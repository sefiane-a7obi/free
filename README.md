# Tenzo Il2Cpp Dumper — نسخة كاملة مع شرح المعمارية

تم استنساخ الموقع بالكامل وبناء السيرفر الخلفي ومحرك المعالجة وربطه بالواجهة التي قمت بسحبها.

---

## 1. هل الملفان اللذان سحبتهما كانا كافيين؟

- **الملف الأول (`مستند نصي جديد.txt`):** هو ملف الـ JavaScript المجمّع (`index-BR2qtfQq.js`) المكتوب بـ React و Vite. يحتوي على كامل الواجهة الأمامية، منطق التحقق، ومحرك فك وقراءة ملفات الـ ZIP/APK داخل المتصفح.
- **الملف الثاني (`مستند نصي جديد (2).txt`):** هو ملف التنسيقات (`index-DvcAW-E4.css`) الذي يحتوي على كافة أنماط التصميم والوضع الليلي وتأثيرات السحب والإفلات.
- **هل كانا كافيين؟**
  - **نعم بنسبة 100% للواجهة الأمامية (Frontend):** جميع واجهات السحب والإفلات، التبويبات، والمؤثرات متوفرة فيهما.
  - **السيرفر الخلفي (Backend):** ملفات المتصفح لا تحتوي على كود السيرفر الذي ينفذ عملية تفكيك الأكواد الحقيقية (وهذا ما أشار إليه صاحب الموقع tenzo في ملاحظته المضمنة في الكود: *"we handle most processing stuff in our serverside so dont try to RE it"*).
  - **الحل:** قمنا ببناء السيرفر الخلفي بالكامل بـ Python FastAPI مع توفير محرك `Il2CppDumper` ليصبح لديك نظام متكامل يعمل بشكل مستقل تماماً على جهازك.

---

## 2. كيف يعمل الموقع تقنياً؟

```
[ملف APK / XAPK] 
       │
       ▼
(1) المتصفح (Client-side)
  - يقرأ ملف APK عبر Web Streams دون الحاجة لرفعه بالكامل.
  - يستخرج فقط: libil2cpp.so + global-metadata.dat
  - يضغطهما بـ Gzip لتقليص الحجم لعدة ميغابايتات فقط.
       │
       ▼  (POST /api/queue/submit)
(2) السيرفر (FastAPI Backend)
  - يستقبل الملفين ويفك ضغط الـ Gzip.
  - يضعهما في طابور مهام (Queue) ويعيد رقم المهمة Job ID.
       │
       ▼  (Background Worker)
(3) محرك المعالجة (Il2CppDumper)
  - يحلل ترويسة global-metadata.dat (نسخ v24 إلى v31).
  - يستخرج C# Pseudo-code والدوال والعناوين والرموز.
  - يجمع الناتج في tenzo_il2cpp_dump.zip
       │
       ▼  (GET /api/queue/download/{job_id})
(4) التحميل التلقائي
  - يحمل المتصفح ملف الـ Zip تلقائياً ويؤكد استلامه ليقوم السيرفر بحذف الملفات المؤقتة.
```

---

## 3. محتويات المجلد بعد التجهيز

- `server.py`: خادم الويب (FastAPI) الذي يدير الـ API وطابور المعالجة.
- `run.bat`: ملف تشغيل سريع بنقرة واحدة للسيرفر.
- `static/`:
  - `index.html`: كود صفحة الويب الأصلية.
  - `assets/index-BR2qtfQq.js`: كود الواجهة التفاعلية.
  - `assets/index-DvcAW-E4.css`: ملف التنسيقات.
- `bin/`:
  - `Il2CppDumper.exe`: محرك التفكيك المباشر.
  - `config.json`, `ida.py`, `ghidra.py`.

---

## 4. كيفية التشغيل

1. شغّل ملف `run.bat` (أو نفّذ الأمر `python server.py` في الطرفية).
2. افتح المتصفح على الرابط: `http://localhost:8000`
3. اسحب أي ملف APK أو XAPK أو ملفات خام (`.so` و `.dat`) واضغط **Start Dump**.
